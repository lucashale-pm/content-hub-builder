# Direct on page content

- Purpose: Add standalone editorial copy directly to a hub page.
- Inputs: Optional heading, optional subheading, zero or more paragraphs, and optional button text/URL.
- States: Any combination of supplied fields; blank fields do not render; button renders as a link when URL supplied; completely blank component is hidden.
- Constraints: Paragraph order follows saved configuration; renderer does not create copy; no brand-specific text or values.
- Reuse: Theme supplies typography and colour tokens. Button uses the shared full-width primary-button treatment. Use for short editorial context, not structured article-card content.
